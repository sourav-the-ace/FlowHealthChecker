# Instructions

## Mandatory

- Never Create, Promote or Install New Package Version without asking
- Never deploy to MyDevHub without permission
- Update the README.md and PROJECT_STATUS.md when needed

# Git Rules

## Do

- Keep commits focused.
- Use descriptive commit messages.
- Review changes before committing.

## Do Not

- Rewrite history unless explicitly requested.
- Force push unless explicitly requested.
- Commit secrets.
- Commit generated files unless required.
- Mix unrelated changes into the same commit.
